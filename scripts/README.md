# Scripts

Hier komen je eigen Python-scripts uit unit 3 en later, bijvoorbeeld:

- `log_analyse.py`: telt mislukte inlogpogingen per IP-adres in `../notities/voorbeeld-auth.log` (unit 3, les 5).
- `wachtwoord_check.py`: beoordeelt hoe sterk een wachtwoord is (unit 3, les 6).

Starten:

```bash
python3 log_analyse.py
```
